# Day 4 – REST API Testing Using Postman

This repository contains my Day 04 submission for the HisabDo SQA Internship Bootcamp.

The objective of this task was to perform **REST API Testing** using Postman by executing different HTTP requests, validating API responses, performing CRUD operations and documenting positive and negative test scenarios.

## API Tested

**JSONPlaceholder REST API**  
https://jsonplaceholder.typicode.com/

## Key Learning Outcomes

- Understanding REST API concepts and CRUD operations
- Working with HTTP methods (GET, POST, PUT, PATCH, DELETE)
- Creating and executing API requests using Postman
- Validating response status codes 
- Verifying JSON response structure and data
- Performing positive and negative API testing
- Identifying API issues and documenting test observations
- Preparing API test cases with expected vs actual results
