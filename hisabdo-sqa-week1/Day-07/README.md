# Day 7 – Mini Test Project

This repository contains my Day 7 submission for the **HisabDo SQA Internship Bootcamp**.

The objective of this task was to perform a complete QA test cycle on the Berryfy application by conducting **Manual UI Testing and API Testing**, covering functional, UI, validation, positive, negative, boundary, usability and cross-browser testing.

## Application & API Tested

**Berryfy Web Application:** https://demo.berryfy.org/

**Berryfy API:** https://api.berryfy.org/

## Learning Outcomes

* Performed manual UI testing of core application workflows.
* Tested registration, login, product search, shopping cart and order functionality.
* Executed positive, negative and boundary test scenarios.
* Performed REST API testing using Postman.
* Validated API status codes, response bodies, required fields and response messages.
* Documented **27 manual test cases and 18 API test cases**.
* Prepared a test execution summary and documented test execution evidence.
