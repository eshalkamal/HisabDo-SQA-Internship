# Day 2 – QA Test Documentation

## Overview

This repository contains my Day 2 submission for the **HisabDo Software Quality Assurance (SQA) Internship Bootcamp**.

The task involved preparing a manual QA test document for a sample **E-commerce Shopping System** based on the provided requirements.

## Objective

The objective of this task was to practice requirement analysis, create comprehensive test scenarios and test cases, apply different manual testing techniques, and document hypothetical defects.

## Modules Covered

* Registration
* Login
* Product Search
* Product
* Shopping Cart
* Checkout

## Testing Techniques Used

* Manual Testing
* Functional Testing
* Positive Testing
* Negative Testing
* Boundary Value Testing

## Deliverables

* Test Scenarios
* Test Cases
* Positive & Negative Test Cases
* Boundary Value Analysis (Password Validation)
* Bug Reports
