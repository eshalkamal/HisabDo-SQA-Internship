# Day 01 – Manual Testing

## Website Tested

- **Website:** Sauce Demo
- **URL:** https://www.saucedemo.com/

## What I Tested

I performed manual testing on the Sauce Demo website by verifying the following functionalities:

- User login with valid credentials
- User login with invalid credentials
- Username and password validation
- Add product to cart
- Remove product from cart
- Shopping cart functionality
- Navigation menu
- Logout functionality
- Product sorting (Price: Low to High)

A total of **10 test cases** were executed, and the observed issue was documented in a bug report.

- Importance of software testing
