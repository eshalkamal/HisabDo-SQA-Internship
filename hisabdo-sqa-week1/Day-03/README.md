# Day 03 – Manual Testing of E-Commerce Website

This repository contains my **Day 03** submission for the **HisabDo SQA Internship Bootcamp**.

The objective of this task was to perform **manual testing** on a publicly accessible e-commerce website by executing test cases across key functional areas and documenting the test results.

## Website Tested

**Demo Web Shop**
https://demowebshop.tricentis.com/

## Testing Scope

The following modules were tested:

* Homepage
* Product Section
* Shopping Cart
* Registration and Login
* Search Functionality
