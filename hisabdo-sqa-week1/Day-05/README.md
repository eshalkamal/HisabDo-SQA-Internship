# Day 5 – REST API Test Suite Using Postman

This repository contains my **Day 5** submission for the **HisabDo SQA Internship Bootcamp**.

The objective of this task was to create a complete **REST API Test Suite** using **Postman** by performing functional, validation and response testing. The API was tested using positive, negative and boundary test scenarios; with test cases, bug reports and supporting evidence documented.

## API Tested

**Fake Store API:**
https://fakestoreapi.com/

## Learning Outcomes

* Understood REST API testing concepts using Postman.
* Performed CRUD (Create, Read, Update, Delete) operations on REST APIs.
* Executed positive, negative and boundary test scenarios.
* Validated API responses using Postman test scripts and assertions.
* Verified HTTP status codes, response body, data types and response time.
* Identified, documented and reported API defects.
