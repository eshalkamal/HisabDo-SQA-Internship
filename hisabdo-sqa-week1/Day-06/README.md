# Day 6 – Authentication API Testing Using Postman

This repository contains my **Day 6** submission for the **HisabDo SQA Internship Bootcamp**.

The objective of this task was to perform **Authentication API Testing** using Postman by testing user authentication workflows, validating API responses, verifying authentication and authorization mechanisms; documenting functional, validation, boundary and security test scenarios.

## API Tested

**FreeAPI Authentication API:** https://freeapi.app/

## Learning Outcomes

* Understood Authentication API testing concepts using Postman.
* Tested user registration, login, logout, email verification and password management APIs.
* Executed positive, negative and boundary test scenarios.
* Validated authentication and authorization using access tokens.
* Verified HTTP status codes, response body, response time and required JSON fields.
* Performed security-related testing using invalid credentials, SQL Injection, XSS payloads and unauthorized access scenarios.
* Created automated Postman test scripts for response validation.
* Documented API test cases, observations and a test summary report.
