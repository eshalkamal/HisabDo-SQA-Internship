This submission is part of the **team-based SQA task for Department 3** and covers **Performance Observations + SEO Validation** of the HisabDo website.

## Work Completed

* Prepared Performance Testing test cases.
* Prepared SEO Validation test cases.
* Performed Lighthouse testing on **10 HisabDo website pages**.

### Performance Testing

* Page Loading Performance
* First Contentful Paint (FCP)

* Cumulative Layout Shift (CLS)
* Overall Lighthouse Performance Score

### SEO Validation

* Overall SEO Score
* Search Engine Crawlability
* Page Metadata
* Crawlable Links
* Lighthouse SEO Best Practices
