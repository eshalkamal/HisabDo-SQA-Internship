# Day 12 – Capstone Project

This repository contains my **Day 12 submission** for the HisabDo SQA Internship Bootcamp.

The objective of this task was to focus on **validation, negative testing and defect verification** by testing major modules of the HisabDo mobile application and website.

## Work Completed

* Executed **20 Mobile App Test Cases**.
* Executed **15 Website Test Cases**.
* Performed testing using:

  * Required-field validation
  * Invalid input
  * Incorrect data formats
  * Boundary values
  * Empty states
  * Error messages
  * Delete and cancel operations
  * Navigation testing
* Identified and documented **4 defects** in the mobile application.
* Created detailed bug reports with:

  * Severity
  * Priority
  * Preconditions
  * Steps to reproduce
  * Expected result
  * Actual result
  * Evidence/screenshots
* Prepared a **Defect Summary Report** containing defect severity and status details.
